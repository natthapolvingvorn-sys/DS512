1. Introduction
การศึกษาถือเป็นปัจจัยสำคัญในการพัฒนาทรัพยากรมนุษย์ อย่างไรก็ตาม นักเรียนบางส่วนอาจประสบปัญหาด้านผลการเรียนจนส่งผลให้มีความเสี่ยงต่อการสอบไม่ผ่านหรือไม่สำเร็จการศึกษา การวิเคราะห์ข้อมูลด้านการศึกษาโดยใช้เทคนิค Machine Learning สามารถช่วยในการระบุนักเรียนที่มีความเสี่ยงได้ล่วงหน้า ทำให้สถาบันการศึกษาสามารถวางแผนให้ความช่วยเหลือและพัฒนามาตรการสนับสนุนได้อย่างเหมาะสม
โครงการนี้มุ่งเน้นการวิเคราะห์ปัจจัยที่ส่งผลต่อผลการเรียนของนักเรียน และพัฒนาแบบจำลอง Machine Learning เพื่อทำนายความเสี่ยงในการสอบตกจากข้อมูลด้านการเรียนและปัจจัยแวดล้อมต่าง ๆ

2. Smart Objectives
Specific
พัฒนาโมเดล Machine Learning เพื่อทำนายว่านักเรียนจะ "สอบผ่าน" หรือ "สอบตก"
Measurable
ให้โมเดลมีค่า Accuracy ไม่น้อยกว่า 80%
Achievable
ใช้ชุดข้อมูล Student Performance Dataset และเทคนิค Machine Learning ที่เหมาะสม
Relevant
ช่วยให้สถานศึกษาสามารถระบุและดูแลนักเรียนกลุ่มเสี่ยงได้อย่างมีประสิทธิภาพ
Time-bound
ดำเนินการวิเคราะห์ พัฒนาโมเดล และประเมินผลภายในระยะเวลาของโครงการ DS512

3. คำถามและสมมติฐาน (Questions / Hypothesis)
คำถาม (Questions)
เพศของนักเรียนมีผลต่อความเสี่ยงในการสอบตกหรือไม่
อายุของนักเรียนมีความสัมพันธ์กับผลการเรียนและโอกาสสอบตกหรือไม่
นักเรียนที่มีเวลาเรียน (Study Time) มากกว่าจะมีโอกาสสอบผ่านสูงกว่านักเรียนที่มีเวลาเรียนน้อยหรือไม่
จำนวนครั้งการขาดเรียน (Absences) ส่งผลต่อความเสี่ยงในการสอบตกหรือไม่
นักเรียนที่เคยสอบตกในอดีต (Failures) มีแนวโน้มที่จะสอบตกซ้ำสูงกว่านักเรียนที่ไม่เคยสอบตกหรือไม่
การได้รับการสนับสนุนจากครอบครัว (Family Support) มีผลต่อผลการเรียนหรือไม่
คะแนนระหว่างภาค (G1 และ G2) สามารถใช้ทำนายผลการสอบปลายภาค (G3) ได้หรือไม่
ปัจจัยใดมีอิทธิพลต่อการสอบตกมากที่สุดเมื่อเปรียบเทียบกับปัจจัยอื่น
Machine Learning สามารถทำนายผลการเรียนของนักเรียนได้อย่างมีประสิทธิภาพเพียงใด
สมมติฐาน (Hypothesis)
นักเรียนที่มีจำนวนครั้งการขาดเรียนสูง มีแนวโน้มสอบตกมากกว่านักเรียนที่เข้าเรียนสม่ำเสมอ
นักเรียนที่มีเวลาเรียนมาก มีแนวโน้มสอบผ่านมากกว่านักเรียนที่มีเวลาเรียนน้อย
นักเรียนที่เคยสอบตกในอดีต มีโอกาสสอบตกในอนาคตสูงกว่านักเรียนที่ไม่เคยมีประวัติสอบตก
การได้รับการสนับสนุนจากครอบครัวและโรงเรียนช่วยลดความเสี่ยงในการสอบตก
คะแนนระหว่างภาค (G1 และ G2) เป็นปัจจัยสำคัญที่สามารถใช้คาดการณ์ผลการเรียนปลายภาคได้
สามารถพัฒนาแบบจำลอง Machine Learning เพื่อทำนายความเสี่ยงในการสอบตกของนักเรียนได้ด้วยความแม่นยำในระดับที่ยอมรับได้
